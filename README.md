# Machine Learning Based Crop Yield Prediction

## Overview
A machine learning web application that predicts crop yield based on agricultural and environmental parameters.

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS

## Machine Learning Model
- Support Vector Machine (SVM)

## Features
- Crop yield prediction
- User-friendly web interface
- Data preprocessing and label encoding
- Agricultural decision support

## Project Structure
- app.py
- Templates
- Static Files
- Model Files (.pkl)
- Database Script (db.sql)
